The part that matters at 1 a.m.

A blocker you can switch off in one click is a suggestion. Flowt puts friction in front of the switch — and only in front of turning things off.

A PIN you set once

Turning any blocker off asks for your four-digit PIN. Turning one back on never does. The settings page is behind the same PIN, so the page where you could disable everything is not a way around it.

The PIN is stored on your device and is never included in a backup file.

Or a reason, in your own words

With accountability mode on, switching Flowt off asks you to type why. The last twenty reasons are kept on the device for you to read later.

Nobody else sees them. That is the point — the audience is you, a week from now.

Three layers, because one is not enough

YouTube renders late, re-renders on navigation, and renames its own internals without notice. A single CSS rule does not survive that.

  1. Layer 1 Stylesheet Rules keyed to attributes on the page element hide known surfaces the moment they paint, with no script in the loop and no flash of the thing you asked to remove.
  2. Layer 2 Page-context script Reads YouTube's own data objects rather than its text, so a sidebar entry is classified by what it links to, not by the word printed on it. Works the same in any interface language.
  3. Layer 3 Network rules Permanent Shorts blocking is a declarative rule in the browser itself. Navigation stops before the page loads, not after you have already seen it.

Three permissions, one site, no server

Flowt makes no network requests of any kind. There is nowhere for your data to go, because there is no backend to send it to.
